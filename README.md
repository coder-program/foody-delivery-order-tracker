# foody-delivery-order-tracker

Estrutura inicial do projeto para rastreamento de pedidos de delivery.

## Estrutura

```
apps/
	web/           # Aplicacao front-end
services/
	api/           # Aplicacao back-end
packages/
	shared/        # Codigo compartilhado (tipos e utilitarios)
docs/            # Documentacao do projeto
```

## Proximos passos

1. Inicializar stack do front-end em `apps/web`.
2. Inicializar API em `services/api`.
3. Definir modelo de pedido e fluxo de status em `packages/shared` e `docs`.
